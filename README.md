# Telegram Bot — Расписание студентов

## Описание

Учебный Telegram-бот для просмотра расписания студентов.

Бот позволяет:

- просматривать расписание на сегодня;
- просматривать расписание на завтра;
- просматривать расписание на неделю;
- получать справочную информацию.

## Используемые технологии

- Python
- aiogram
- Telegram Bot API
- unittest
- python-dotenv
